# IoT Smart Room and Garage Security System

## About
An IoT-based smart room and garage system built with Cisco Packet Tracer. It uses motion and smoke sensors to automate garage access and respond to potential fire hazards. A laptop and IoT server allow monitoring of the camera and controller logs.

## Technologies Used
- Cisco Packet Tracer
- Internet of Things (IoT)
- Motion Sensor and Smoke Sensor
- MCU and SBC Controllers
- Web Camera
- IoT Server
- DHCP and DNS Servers
- Wi-Fi Router and Network Switch

## Features
- **Automatic Garage Access:** Motion detection triggers the garage door to open.
- **Smoke Detection:** Detects smoke and activates the safety response.
- **Automatic Ventilation:** Opens the windows and turns on the fan when smoke is detected.
- **Audio and Visual Alarms:** Uses a speaker and siren to provide alerts.
- **Camera Monitoring:** Monitors the garage and room through the camera.
- **Centralized Monitoring:** Uses a laptop and IoT server to monitor the system and controller logs.

## What Users Can Do
- Monitor the room and garage through the camera.
- Check sensor activity and controller logs.
- Observe automatic responses to motion and smoke.
- Monitor connected IoT devices through the network.

## How It Works
1. Motion sensors detect movement in the room.
2. The controller processes the sensor input and triggers the garage door to open.
3. The camera monitors the area, while the speaker and alarms provide alerts when configured.
4. When smoke is detected, the system opens the windows and turns on the fan.
5. The IoT server and laptop provide centralized monitoring of the devices and controller logs.

## What I Learned
- Connecting and configuring IoT devices in Cisco Packet Tracer.
- Using sensors and controllers to automate actions.
- Creating network connections between IoT devices, servers, and computers.
- Understanding how smart home automation and monitoring systems work.

## How to Run the Project
1. Install Cisco Packet Tracer.
2. Clone or download this repository.
3. Open the `.pkt` project file in Cisco Packet Tracer.
4. Start the simulation and test the motion and smoke sensors.
5. Verify the garage door, windows, fan, alarms, and monitoring setup.
